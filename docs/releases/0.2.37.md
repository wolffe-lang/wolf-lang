## Calls through held directories

The descriptor walk adds ten filesystem builtins:

- `fs_open_at(dir, name, open, perm)` opens relative to a held directory.
- `fs_stat_at(dir, name)` and `fs_lstat_at(dir, name)` read the twenty-word
  file record, following or not following the final symbolic link.
- `fs_remove_at(dir, name)` removes an entry; `fs_remove_dir_at(dir, name)`
  removes an empty directory.
- `fs_create_dir_at(dir, name, mode)` creates a directory under the handle.
- `fs_symlink_at(target, dir, name)` stores the target verbatim.
- `fs_link_at(src_dir, src, dst_dir, dst, follow)` links between handles.
- `fs_read_dir_entries_at(dir)` lists the held directory, rewinding a
  duplicate so another read starts at the beginning.
- `fs_set_mode_fd(fd, mode)` changes the file a handle holds, even if
  another file has since replaced its path.

An empty or absolute relative name is `invalid` before a host call.
`ENOTDIR` and `ELOOP` map to `invalid`, with the host error in `os_error()`.
Names containing `..` or multiple components retain host lookup semantics;
confinement requires walking one component at a time, not passing an
unchecked multi-component name. Windows answers the new calls
`unsupported` after checking their shapes. All ten are `fs`-charged and
refused at comptime. See `[os.fs.at]` and `[os.fs.mode.fd]` in
[the OS specification](../../spec/11-os.md).

The open word's **bit 32** is `O_DIRECTORY`, on `fs_open_mode`,
`fs_open_perm` and `fs_open_at`. It accepts only the two read modes.
A non-directory is `invalid` with `ENOTDIR`; a FIFO is refused without
opening it. Combine it with bit 16 for no final symbolic-link following.
Write modes and Windows reject the bit before a host call. Opens without
bit 32 keep their existing behavior. See `[os.fs.open.directory]`.

## OS records, signals and terminal output

`fs_statfs(path)` returns a twelve-word filesystem record with a `have`
mask. `os_chroot(path)` changes only the root, not the current directory;
call `os_chdir("/")` separately when that is wanted. `os_getpriority()`
reads niceness, and `os_setpriority(delta)` changes it by a saturating,
clamped delta. `os_signal_action_one(meaning)` reads one signal action
without changing it: default, ignored or another handler.

Terminal mode bit 24, `RAW_LF`, clears `ONLCR` while leaving output
processing available. Reading and restoring a mode preserves the caller's
newline mapping. A hand-built mode leaving `RAW_LF` clear now enables
newline mapping; bit 25 and above remain invalid.

The signal hub's drain thread survives a fork interrupting its poll:
errno is saved before the fork park can overwrite it, temporary poll
failures are retried, and a dead drain wakes waiters and can be restarted.
Repeated failure within one wait reports `io` rather than parking forever.

## Compiler corrections and bounded memory

The release optimizer propagates writes through relayed `mut` List
parameters and recognizes when a callee replaces the caller's List.
Error display reads the active union tag's payload, and bare enum variants
initialize inactive pointer-bearing slots. These address the wrong answers
in [PR 992](https://github.com/wolffe-lang/wolf-lang/pull/992).

A plain push of a heap value into a List outliving a region block is
refused with E1010. Use `push(copy value)` to copy into the List's own
region, or `push(take value)` to move it. Allocation size does not make an
escaping region header safe.

A direct `for` over `m.pairs()` can walk the Map's own entries without
allocating a snapshot when its body does not name the Map. Other shapes
retain snapshot semantics. Checked Lists and Maps reuse their high-water
storage after reset, clear, pop or remove. Bounded-memory regression tests
now distinguish their sensitivity controls from sub-floor RSS changes.

## Truthful diagnostics and build progress

[PR 997](https://github.com/wolffe-lang/wolf-lang/pull/997) makes test
failures retain assertion messages, source sites and equality operands,
including optional JSON assertion details. `fmt` and `fmt --check` reject
parser failures. `fix` explains unapplied suggestions and returns failure
when the program remains invalid after edits. A lent-value refusal has
code E1016 and a source site, while retaining exit 4. The nightly property
sweep receives verified linker inputs and a head-built musl runtime;
formatter regression coverage preserves the already-correct multiline
if-argument layout.

Long build/run/test compilations report units and phases on a terminal.
Non-interactive builds wait for 30 seconds of silence before a heartbeat,
then report every 60 seconds. `--quiet` suppresses status, not diagnostics;
`--timings` and `--timings=json:<file>` record scoped elapsed contributions.
See [the CLI timing schema](../cli.md). PR CI routing now distinguishes
cheap checks, labelled full/release checks and shared-path trunk changes.

## Paired interpreter and standard library

Lupin 0.1.59 mirrors byte arguments and invocation names, OS identity,
C-variadic refusals, aggregate lending, Map-walk/storage reuse and updated
region-store conformance, with its own bounded signal/exec corrections.
It does **not** mirror either new OS surface in this release:

| Surface | Compiler native/checked | Published lupin 0.1.59 |
| --- | --- | --- |
| OS records, root, priority and action query | served with documented host limits | unresolved-name `unsupported` cells |
| terminal `RAW_LF`, bit 24 | served | older mode shape, bit 24 invalid |
| descriptor-relative calls and handle mode changes | served on Unix; Windows limitations above | unresolved-name `unsupported` cells |
| directory-open bit 32 | served on Unix read modes | older open word, directory open refused |

The mirrors are tracked in [issue 315](https://github.com/wolffe-lang/wolf-interp/issues/315)
and [issue 321](https://github.com/wolffe-lang/wolf-interp/issues/321).
In particular, the published interpreter's `open_directory` corpus row
exits successfully but reports `directory: false`; an exit alone does not
establish a mirror. Release verification preserves these measured cells
instead of treating a version bump as implementation coverage.

The bundled std includes leap-aware local time, the byte-list string
builder, `env.arg0` and `env.args_bytes`, and bounded incremental SHA-2.
SHA-256/SHA-512 schedules and block buffers are reused; SHA-384 and the
HMAC/HKDF callers share the correction without signature or digest changes.
The fixed tree contains 561 tests and 554 doc examples, not a claim that
all interpreter ledger cells run. A downstream package reader benefits
from the bounded hash storage.
