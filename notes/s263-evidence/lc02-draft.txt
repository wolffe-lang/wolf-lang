1. Goal and non-goals
Take the tested bare %d %s %c %x %% formatter from s263 to a maintained,
freestanding first formatted-output layer, and add va_list consumers and
bounded buffer output using one shared Wolf formatter. The standard is the
contract; glibc is a black-box comparison, not source or policy authority.
This is not a full libc printf claim and not the FILE/stream lane.

In scope: printf, vprintf, snprintf, vsnprintf for exactly bare %d %s %c %x %%
initially; explicit documentation of the supported conversion grammar;
character/byte correctness, return counts, bounded-buffer semantics, error
paths, existing first-layer regressions and native/release parity.
Out of scope: FILE, fopen/fclose/fread/fwrite/fprintf, stream locking/buffering,
scanf, floats, locale/wide characters, flags/width/precision/length modifiers,
%n, thread safety, signal safety, arbitrary callbacks, shared-library ABI,
other architectures/ABIs, checked/lupin execution and PAX port claims.
An expansion beyond this scope requires an orchestrator ruling and tests;
never advertise an unsupported conversion as ordinary printf functionality.

3. Items (tests accompany implementation)
1) Reproduce s263 acceptance untouched before changing it. Record exact
   compiler version/head/archive digest, object symbols, native/release
   commands and true exits. Confirm x86_64-unknown-none, no libwolf_rt.a,
   no unresolved external, no dynamic interpreter, C17 -nostdlib -static.
   Recheck all fifty primary cases and all prior first-layer cases.
2) Pin a released compiler carrying the accepted freestanding clause using
   tools/fetch-toolchain and the whole release archive. Preserve the strict
   default build identity check and stale-output deletion. Remove the
   acceptance-only version override before merge (or seek a ruling to keep
   it behind an explicit test-only interface); prove wrong/missing/stale
   compiler refusals and correct-pin controls on both compiling tiers.
3) Factor the formatter into an explicit sink-state record, not a C callback:
   an output-fd sink and a bounded-memory sink. Keep all parsing/conversion
   logic Wolf. No new asm formatting or C formatting shim. Keep allocation
   and runtime-free linking. Ensure INT_MIN widening, unsigned hex, %c's
   unsigned-char conversion (including NUL), byte-oriented %s, and %%.
4) Add vprintf(fmt: *u8, ap: *VaList), copying the incoming live record,
   consuming/ending the copy. C is not promised cursor preservation as a
   standard API property, but test independence internally. printf owns one
   va_start/end and delegates. Add C -> Wolf va_list tests (C's own builtin
   start/copy/end compiled by clang; never inspect implementation headers),
   Wolf -> consumer forwarding, repeated copies, register-to-stack boundary,
   zero variadic arguments, and nested/repeated calls within live lifetimes.
5) Add snprintf and vsnprintf with the standard bounded destination model:
   size 0 writes nothing and permits a null destination; positive size
   reserves the final NUL, emits at most size-1 bytes, and returns the full
   would-have-written count excluding NUL. Truncation is success; embedded
   NUL from %c counts as data. Disallow overlapping arguments/destination
   as the C standard does; no test relies on undefined overlap. Check count
   overflow without allocating gigantic strings. Ends must run on errors.
6) Harden output errors and record the subset refusal policy. Test a closed
   fd, /dev/full, forced EINTR and partial writes with lane-owned fault
   injection or an independently tested syscall shim. Distinguish an error
   before output from a prefix already emitted. Do not compare buffering
   timing to hosted glibc; compare required returns/errno and final bytes.
   Check zero progress cannot loop forever. Keep error state and formatting
   state separate; no corrupting the trap hook's scratch storage.
7) Grow the corpus: retain all s263 fifty cases and add at least fifty
   independently expected buffer/va_list cases, with an explicit inventory
   by conversion, boundary, promotion and error path. Every test records
   full output bytes, return count and true exit. Check canary bytes before
   and after bounded destinations (sizes 0,1,exact,one-short,large), NUL
   termination, count at truncation, stack spills of each supported type,
   and repeated calls. Use byte comparison, not line comparison or hashes
   alone; hash the corpus and outputs additionally for evidence.
8) CI: native and release Ubuntu x86-64 builds, all old/new differential
   cases, pin/refusal tests, symbol/no-runtime gates. No silent skip when
   compiler/header/clang is absent; no empty suite green. Local container
   gate first; run-id once after push and hand back at final head per lane
   rules. The orchestrator owns any later CI watch/label/merge.
9) Update README, LEDGER and SOURCES to name exact supported conversions,

   C17/POSIX stdio conformance claim. Remove obsolete blockers only after
   a witness proves them resolved. No hosting/deployment claims.

4. Plants and independent acceptance
- Flip one numeric digit or skip the sixth unnamed GP argument: differential
  must fail on both compiling tiers and identify the first differing case.
- Corrupt the return count without changing bytes: independent count gate red.
- Write one byte at destination[size] or omit the terminating NUL: canary/NUL
  gate red. Preserve the planted evidence and restore the fix before handoff.
- Replace the expected compiler with a stale driver, and retain an old
  archive before refusal: identity gate red, old build directory absent.
- Remove the new cases or make discovery empty: inventory/zero-case gate red.
Record exact planted commits/commands/exits; a gate never seen red is unproven.
Do not plant in shared trunk; use lane-owned plant branches granted in brief.

5. Rulings to recommend, never decide
R-lc02-1: Keep this bounded printf-family slice distinct from full FILE stdio
(recommended); or enlarge the lane only after callback/TLS/state blockers are
resolved and a new test budget/scope is approved.
R-lc02-2: Unsupported conversions return -1/EINVAL after any emitted prefix
(recommended for this explicitly documented subset), rather than silently
printing unknown syntax. This is not full standard printf compatibility.
R-lc02-3: Retain the explicit single-threaded first cut until the TLS/stream
lane (recommended); do not infer reentrancy from passing ordinary tests.
R-s263-8 A has been confirmed: true freestanding SysV support, ordinary
float prohibition retained, guarded vector saves in variadic entry only.
Verify its final clause and implementation at the released pin; a hosted
Linux compile is never acceptance for muzzle's real target.
